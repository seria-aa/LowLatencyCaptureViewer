# Low Latency Capture Viewer — v0.16.0

> [English README](README.md)

Windows x64용 초저지연 캡처 뷰어입니다. AVerMedia GC573를 기준으로 개발했으며,
비압축 NV12/YUY2를 제공하는 다른 DirectShow 캡처카드도 실험적으로 지원합니다.
외부 미디어 플레이어, 디먹서, 디코더, FFmpeg는 사용하지 않습니다.

## 주요 특징

- 단일 DirectShow 필터 그래프에서 영상과 오디오를 함께 캡처
- 최신 영상 샘플 하나만 유지하고 오래된 프레임은 버림
- D3D11 텍스처와 Video Processor를 통한 직접 렌더링
- DXGI flip-discard 스왑체인, 최대 프레임 지연 1
- VSync 또는 Tearing 허용 선택
- WASAPI Shared(`IAudioClient3` 지원 시 사용) 또는 Exclusive 선택
- Windows 기본 출력 장치 추적 또는 특정 WASAPI 장치 고정
- 선택 가능한 PCM 버퍼 목표와 클록 드리프트 보정
- Tab 키 실시간 정보 OSD, 마우스 휠 볼륨 조절, 선택적 백그라운드 음소거
- 픽셀 퍼펙트 1:1, 모니터 상대 창 크기 유지, 멀티 모니터 스냅

## 동작 구조

```text
DirectShow 캡처 필터
├─ 영상: NV12/YUY2 → 최신 샘플 슬롯 → D3D11 텍스처 → Video Processor → Present
└─ 오디오: 48 kHz PCM → 제한된 PCM 링 → WASAPI Shared/Exclusive 출력
```

영상은 A/V 동기화나 타임스탬프 스케줄링을 사용하지 않습니다. 오디오가 영상
프레임을 큐에 쌓게 만들지 않으며, DirectShow 그래프에도 별도 기준 클록을
설정하지 않습니다.

## 설정 항목

- 오디오 출력 모드: WASAPI Shared / WASAPI Exclusive
- WASAPI 출력 장치: Windows 기본 장치 따라가기 또는 특정 장치 고정
- WASAPI 버퍼: 장치가 지원하는 Shared 주기 또는 Exclusive 5/10/15/20/30/40 ms
- 클록 드리프트 보정: 끔(원본 PCM, 기본값) 또는 자동 리샘플링
- PCM 버퍼 목표: 10/15/20/30 ms. 리샘플링과 별도로 조정됩니다.
- 캡처 장치: GC573 우선 자동 선택 또는 특정 DirectShow 장치
- 캡처 해상도: 1920×1080, 2560×1440, 3840×2160
- 픽셀 포맷: 자동, NV12, YUY2
- 프레임: 자동, 장치가 제공하는 120/60 fps 등
- Pixel-perfect: 선택 시 정확한 1:1 클라이언트 영역으로 고정하고 마우스 크기
  조절을 막습니다. 해제하면 영상 비율을 유지한 채 마우스로 크기를 조절합니다.
- 모니터 이동 시 상대적 창 크기 유지: Pixel-perfect와 독립적으로 동작합니다.
  두 옵션을 함께 켜면 다른 모니터에서 1:1이 깨질 수 있습니다.
- 제목 표시줄 숨기기, 작업 영역 가장자리 스냅, 진단 로그 저장
- 백그라운드 창이 되면 자동 음소거(기본값 끔)

선택한 해상도가 현재 모니터와 같고 Pixel-perfect가 켜져 있으면 자동으로
borderless 전체화면으로 전환됩니다. 설정은 실행 파일 옆의 `settings.ini`에
저장됩니다.

## 지원 범위

GC573가 테스트 및 권장 장치입니다. 다른 장치는 실험적 기능이며 다음 조건이
필요합니다.

- 비압축 progressive NV12 또는 YUY2 영상 모드
- 위의 세 해상도 중 하나
- 같은 DirectShow 캡처 필터에 48 kHz 스테레오 PCM 오디오 핀

압축 포맷, P010, 별도 USB 오디오 필터는 이 버전에서 연결하지 않습니다.
장치 재연결 자동화도 의도적으로 포함하지 않았습니다. 장치를 재연결한 뒤에는
프로그램을 다시 시작하세요.

장치와 해상도를 설정 창에서 바꾸면 `IAMStreamConfig` 기능을 한 번 조회하여
사용 가능한 포맷과 프레임을 표시합니다. 이 조회는 캡처 중에 실행되지 않으므로
렌더링 지연을 추가하지 않습니다.

## 조작법

- `F11`: borderless 전체화면 전환
- `Tab`: 실시간 정보 OSD 표시/숨기기
- 영상 위에서 마우스 휠: 애플리케이션 볼륨을 5% 단위로 조절
- 창을 모니터 가장자리나 모서리로 끌기: 창 크기를 바꾸지 않고 스냅
- `Shift` 누른 채 드래그: 일시적으로 스냅 무시
- `Esc`: 전체화면 해제, 창 모드에서 다시 누르면 종료

## OSD 읽는 법

OSD에는 입력 콜백 FPS, Present FPS, 애플리케이션 처리 시간, 교체된 프레임,
현재 포맷과 표시 방식, WASAPI 실제 버퍼/점유량, 캡처 패킷 주기, PCM 버퍼,
리샘플러 보정 ppm, 오디오 오류가 표시됩니다.

프로그램 시작 후 2초 동안은 진단 카운터 워밍업을 하므로 FPS와 underrun/overrun
통계가 본격적으로 집계되지 않습니다. 캡처·렌더링·오디오 출력은 즉시 시작됩니다.

클록 보정의 추정 ppm은 하드웨어 클록을 직접 측정한 값이 아닙니다. Windows 스케줄링
지연과 시작 직후의 변동도 포함합니다. 최소 10~30분 관찰한 뒤 판단하세요. 최근 오류가
시간당 반복되거나 추정 불균형이 커질 때만 리샘플링을 고려하는 것이 좋습니다.

OSD 용어는 다음과 같습니다.

- `출력 버퍼`: WASAPI 장치 버퍼
- `출력 점유`: 해당 출력 버퍼에 현재 들어 있는 양
- `PCM 버퍼`: 캡처와 WASAPI 사이에 있는 프로그램 내부 링 버퍼
- `PCM 버퍼 목표`: 내부 링 버퍼의 안전 목표량

underrun은 입력 콜백 지연, PCM 안전 큐 부족, 리샘플러 출력 부족으로 분류됩니다.
가끔 한 번 발생한 underrun은 즉시 음질 문제를 뜻하지 않지만, 반복되면 PCM 버퍼
목표를 올리거나 클록 보정을 검토하세요. 10 ms는 최저 지연·높은 끊김 위험,
15 ms는 저지연 리샘플링 권장, 20 ms는 안정성 우선 기본값, 30 ms는 스케줄링
지터가 큰 PC용입니다.

## 영상 지연과 메모리 복사

최신 `IMediaSample`을 참조로 유지하고 오래된 샘플을 큐에 쌓지 않습니다.
2560×1440 @ 120 fps에서 불필요한 CPU 복사를 약 633 MiB/s 줄입니다. GC573
드라이버가 D3D11 표면을 제공하지 않아 시스템 메모리에서 D3D11로 한 번 복사하는
경계는 남아 있습니다. 이는 캡처 드라이버의 동작이며 안전하게 제거할 수 있는
애플리케이션 큐가 아닙니다.

## 오디오 및 볼륨

테스트한 GC573 드라이버는 `IAMBufferNegotiation` 요청을 무시하고 480 프레임
(10 ms) PCM 패킷을 항상 생성합니다. 따라서 설정에서 의미 없는 캡처 버퍼 크기는
제공하지 않고, 실제 패킷 주기만 OSD에 표시합니다.

클록 보정이 꺼져 있으면 PCM 샘플은 리샘플링 없이 WASAPI로 전달됩니다. 켜면
16-tap windowed-sinc 보간기가 최대 ±1000 ppm 범위에서 소비 속도를 조정합니다.
안정성은 좋아지지만 샘플이 변경되고 약간의 안전 대기량이 필요하므로, 원본 음질과
최저 지연을 원하면 끔을 사용하세요.

볼륨은 0~100% 감쇠만 지원합니다. 100%에서는 PCM 게인 연산을 우회하며, 다른
값에서는 클릭 방지를 위해 짧은 게인 램프를 사용합니다. 백그라운드 자동 음소거는
캡처와 PCM 소비를 멈추지 않고 렌더 게인만 0으로 낮추므로 복귀 시 오디오를
재시작하거나 지연을 누적시키지 않습니다.

## 빌드

Visual Studio 2022 x64 개발자 PowerShell에서 실행합니다.

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
```

빌드 후 `build\Release\LowLatencyCaptureViewer.exe`를 실행합니다. 별도의
mpv.exe나 FFmpeg DLL은 필요하지 않습니다.

필요한 환경:

- Windows 10/11 x64
- Microsoft Visual C++ 2015–2022 Redistributable x64
- DirectShow 캡처카드 드라이버
- D3D11, DXGI, DirectShow, WASAPI Windows 구성요소
