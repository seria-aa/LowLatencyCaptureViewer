# Low Latency Capture Viewer

> [English](README.md) · [최신 버전 다운로드](https://github.com/seria-aa/LowLatencyCaptureViewer/releases/latest)

HDMI 캡처보드의 영상과 소리를 **가볍고 낮은 지연으로** 표시하는 Windows 뷰어입니다.
캡처 영상을 DirectShow에서 받아 D3D11로 바로 표시하고, 캡처 오디오는 선택한 출력
장치로 직접 보냅니다. 오래된 프레임을 쌓아 두지 않고 최신 프레임을 우선하므로,
캡처보드 화면을 창으로 띄워 두거나 직접 보며 사용할 때 적합합니다.

FFmpeg, 코덱 팩, 별도 Visual C++ 재배포 패키지는 필요하지 않습니다.

## 다운로드

[최신 릴리스](https://github.com/seria-aa/LowLatencyCaptureViewer/releases/latest)에서 둘 중 하나를 받으세요.

- **Setup.exe — 권장:** 설치, 시작 메뉴 바로가기, 제거 프로그램을 제공합니다.
- **x64.zip — 포터블:** 압축을 푼 뒤 `LowLatencyCaptureViewer.exe`를 실행합니다.

Windows 10/11 x64와 캡처보드 드라이버가 필요합니다.

## 처음 사용하기

1. OBS, 제조사 캡처 유틸리티 등 캡처보드를 열어 둔 프로그램을 모두 종료합니다.
2. 앱을 실행합니다.
3. **캡처 장치**가 맞는지 확인하고 **시작**을 누릅니다.

처음에는 기본값 그대로 사용해도 됩니다. 기본값은 1080p, 저지연 표시, WASAPI
Shared, PCM 버퍼 20ms, 자동 클록 보정입니다.

영상은 나오는데 소리가 없으면 **캡처 오디오 장치**를 확인하세요. USB 캡처보드처럼
영상과 오디오가 별도 장치로 표시되는 경우에는 같은 이름의 오디오 장치를 직접
선택해야 합니다. “영상 장치 내부 오디오 감지됨 · 자동 사용”이라고 보이면 따로
선택할 필요가 없습니다.

## 무엇을 고르면 되나요?

### 영상

| 항목 | 처음에는 이렇게 사용하세요 |
| --- | --- |
| 캡처 해상도 | **1920 × 1080**. 콘솔·캡처보드 입력과 맞게 변경 |
| 픽셀 포맷 | **자동 선택 (NV12 우선)** |
| 프레임 | **자동 선택** 또는 입력 기기의 실제 출력 프레임과 동일하게 설정 |
| 화면 표시 방식 | **저지연(최소 지연)**. 화면 찢어짐이나 모니터 신호 끊김이 있으면 **VSync(호환성 우선)** |
| Pixel-perfect | 선명한 1:1 표시가 필요하면 켬, 자유로운 창 크기 조절이 필요하면 끔 |

120fps 입력이라도 게임 자체가 매 프레임 새 영상을 내보내지 않으면 추가 화면 정보가
생기지는 않습니다. 캡처 프레임은 캡처보드와 입력 기기가 실제로 지원하는 값 안에서
선택하세요.

### 오디오

| 항목 | 처음에는 이렇게 사용하세요 |
| --- | --- |
| 오디오 출력 모드 | **WASAPI Shared** |
| 출력 장치 | **Windows 기본 출력 장치 따라가기** |
| 오디오 출력 버퍼 | 설정 창의 권장값 |
| PCM 버퍼 목표 | **20ms** |
| 클록 드리프트 보정 | **자동** |

WASAPI Shared는 다른 앱·Windows 효과와 함께 쓰기 쉬운 기본 모드입니다. ASIO는
ASIO 드라이버가 설치된 경우에만 나타나는 실험 기능입니다. WASAPI Exclusive는
장치별 재생 검사에 통과한 장치에서만 선택할 수 있습니다. 특별한 이유가 없다면
WASAPI Shared를 사용하세요.

소리가 간헐적으로 끊기면 Tab 진단창에서 **버퍼 부족** 또는 **리샘플러 출력 부족**이
반복되는지 확인한 뒤 PCM 버퍼를 `20 → 25 → 30ms`로 올리세요. 오류가 없으면 굳이 더
낮추거나 높일 필요가 없습니다.

## 자주 쓰는 기능

| 기능 | 사용법 |
| --- | --- |
| 설정 다시 열기 | `F2` |
| 실시간 정보창 | `Tab` |
| 오디오 미터 | `F3` |
| Pixel-perfect 크기 복원 | `F5` |
| 보더리스 전체화면 | `F11` |
| `Esc` | 자동 전체화면 종료, F11 전체화면 해제 |
| 앱 음량 | 뷰어 위에서 마우스 휠 — 5% 단위 |
| L/R 개별 음량 | `F3` 후 L 또는 R 카드 위에서 마우스 휠 |
| 스냅 무시 | `Shift`를 누른 채 창 드래그 |

Pixel-perfect를 켜면 영상 픽셀과 화면 픽셀을 1:1로 맞춰 흐림을 줄입니다. 대신 창
크기가 고정됩니다. 끄면 종횡비를 유지한 채 창 크기를 자유롭게 조절할 수 있으며,
설정에서 부드럽게/선명하게 확대 방식을 고를 수 있습니다.

전체화면에서는 마우스를 2초 동안 움직이지 않으면 커서가 자동으로 숨겨지고,
움직이거나 휠을 쓰면 다시 나타납니다. 원하면 영상·창 탭에서 항상 표시로 바꿀 수
있습니다.

**다음 실행부터 바로 시작**을 켜면 이후 설정 창을 건너뜁니다. 실행할 때 `Shift`를
누르거나 뷰어에서 `F2`를 누르면 다시 설정을 열 수 있습니다.

## 문제 해결

| 증상 | 먼저 해 볼 일 |
| --- | --- |
| 화면이 안 나옴 | OBS·제조사 프로그램을 종료하고 캡처 장치/해상도/포맷을 자동 선택으로 되돌리기 |
| 저지연 모드에서 모니터 신호가 잠깐 끊김 | 그래픽 드라이버의 Tearing 표시 경로와 호환되지 않을 수 있으므로 화면 표시 방식을 **VSync**로 변경. 보더리스 창은 그대로 사용 가능 |
| 소리가 안 남 | 캡처 오디오 장치에서 영상 장치에 대응하는 오디오 입력 선택 |
| 소리가 가끔 끊김 | Tab 진단창에서 버퍼 부족 여부를 확인하고 PCM 버퍼 목표를 5ms씩 올려 재시험 |
| 원인 확인이 필요함 | 안내·진단 탭에서 로그 저장을 켠 뒤 문제를 재현하고, **로그 폴더 열기**에서 생성된 최신 `.log` 파일과 설정 화면/Tab 진단창 캡처를 함께 전달 |

설정과 선택적 진단 로그는 `%LOCALAPPDATA%\LowLatencyCaptureViewer`에 저장됩니다.
제거 프로그램은 이 사용자 데이터를 함께 지울지 선택할 수 있습니다.

## 호환성 및 실험 기능

AVerMedia GC573에서 주로 개발·검증했습니다. 다른 DirectShow 캡처보드도 지원하지만
장치별 드라이버 차이 때문에 모든 모델을 보장할 수는 없습니다.

- 기본 지원: 48kHz 스테레오 PCM 오디오, progressive NV12/YUY2 영상
- 호환 모드: MJPEG — 장치가 제공하면 항상 목록에 표시되며 직접 선택, 디코더
  메타데이터를 우선해 색 범위와 BT.601/709를 자동 적용. 색이 다른 앱과 다르면
  MJPEG 선택 시 나타나는 **MJPEG 색상 해석**에서 조합을 직접 지정 가능
- 실험 기능: ASIO 출력, P010 10-bit HDR10
- 미지원: H.264/AVC, MPEG-4, 자동 장치 재연결

P010 HDR10은 장치가 신뢰할 수 있는 BT.2020/PQ 메타데이터를 제공할 때만 사용하세요.
일반 SDR 환경에서는 자동 선택을 유지하는 편이 안전합니다.
