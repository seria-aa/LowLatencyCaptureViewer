# Low Latency Capture Viewer

> [English](README.md) · [최신 버전 다운로드](https://github.com/seria-aa/LowLatencyCaptureViewer/releases/latest)

HDMI 캡처보드의 영상과 소리를 최대한 짧은 경로로 전달하도록 설계한 Windows용
초저지연 뷰어입니다. 장면 합성이나 인코딩처럼 뷰어에 불필요한 처리 단계를 두지
않고 캡처와 표시에 집중해 가볍고 빠르게 동작합니다.

영상은 DirectShow에서 받아 D3D11로 표시하고, 오디오는 WASAPI로 직접
출력합니다. 설치된 ASIO 드라이버가 있을 때만 선택할 수 있는 실험적 ASIO
출력도 제공합니다. FFmpeg, 서드파티 코덱 팩이나 별도 Visual C++ 재배포
패키지는 필요하지 않습니다.

## 다운로드

[최신 릴리스](https://github.com/seria-aa/LowLatencyCaptureViewer/releases/latest)에서 받을 수 있습니다.

- **Setup.exe** — 일반 사용자에게 권장합니다. 시작 메뉴 바로가기와 제거
  프로그램을 설치합니다.
- **x64.zip** — 포터블판입니다. 압축을 풀고
  `LowLatencyCaptureViewer.exe`를 실행하면 됩니다.

Windows 10/11 x64와 캡처보드 드라이버가 필요합니다.

## 빠른 사용법

1. OBS Studio, Elgato 4K Capture Utility 등 캡처보드를 사용 중인 다른
   프로그램을 종료합니다.
2. Low Latency Capture Viewer를 실행합니다.
3. 캡처 장치, 캡처 오디오 장치, 해상도, 포맷, 프레임과 오디오 출력 장치를
   확인합니다.
4. **시작**을 누릅니다.

처음에는 설정 창에 표시되는 권장값을 사용하면 됩니다. USB 캡처보드의 영상과
오디오가 별도 장치로 나타난다면 **캡처 오디오 장치**에서 대응하는 입력을
선택하세요.

영상 없이 소리만 듣고 싶다면 **오디오 only 모드**를 켜세요. 이 모드에서는
비디오 핀과 D3D11 표시 경로를 열지 않고 오디오 입력과 선택한 오디오 출력만 실행합니다.
영상 뷰어와 같은 L/R 피크·dBFS·채널/마스터 음량·클리핑 OSD를 표시합니다.
`F2`로 설정을 다시 열고, `F3`으로 오디오 미터 OSD를 표시하거나 숨길 수 있으며,
`Esc`로 종료할 수 있습니다.

## 주요 기능

- 오래된 프레임을 쌓지 않고 최신 프레임만 표시
- D3D11 Video Processor, flip-discard 표시, 최대 프레임 지연 1
- 저지연 표시 또는 VSync 선택
- WASAPI Shared와 `IAudioClient3` 저주기 출력 지원
- 설치된 드라이버가 있을 때만 표시되는 실험적 ASIO 출력
- 장치별 해상도, NV12/YUY2/MJPEG/P010과 프레임 자동 인식
- 메타데이터 확인과 SDR 대체 경로를 포함한 P010 10-bit HDR10 실험 경로
- Pixel-perfect 1:1, 비율 고정 크기 조절, 보더리스 전체화면과 F5 복원
- 멀티 모니터 DPI 대응 창 크기 유지와 가장자리 스냅
- 볼륨 조절, 백그라운드 자동 음소거, 로그와 Tab 실시간 정보창
- 영상 없이 캡처 오디오와 선택한 출력만 사용하는 **오디오 only 모드**

## 권장 시작 설정

| 항목 | 권장값 |
| --- | --- |
| 화면 표시 방식 | **저지연**. 찢어짐 방지가 더 중요하면 VSync |
| 오디오 출력 모드 | 호환성이 높은 **WASAPI Shared** |
| 출력 장치 | **Windows 기본 출력 장치 따라가기** |
| 캡처 포맷 | **자동 선택 / NV12 우선** |
| 캡처 프레임 | 입력 기기가 실제 출력하는 프레임과 동일하게 설정 |
| PCM 버퍼 목표 | **10ms**. underrun이 반복될 때만 높임 |
| 클록 드리프트 보정 | 기본은 **끔**. 장시간 불균형이 보이면 **자동**; 항상 보정하려면 켬 |
| Pixel-perfect | 정확한 1:1은 켬, 자유로운 창 크기 조절은 끔 |

현재 버전에서는 점검 중인 WASAPI Exclusive를 설정 화면에서 임시로 숨겼습니다.
기존 설정이 Exclusive로 저장되어 있어도 다음 실행에서는 WASAPI Shared로 전환됩니다.

ASIO는 설정 창에서 ASIO 드라이버가 감지될 때만 나타납니다. ASIO 드라이버는
프로그램에 포함하지 않으며, 드라이버가 제공하는 버퍼 크기를 사용합니다. 현재
캡처 오디오와 같은 48kHz 드라이버만 사용할 수 있습니다. ASIO에서도 클록
드리프트 보정의 끔/자동/켬을 사용할 수 있습니다. 출력 클록은 ASIO 드라이버가
담당하고, 필요할 때 앱 리샘플러가 캡처 PCM 속도만 미세 조정하므로 별도 대기열을
추가하지 않습니다. Windows 오디오 효과가 필요하면 WASAPI Shared를 사용하세요.
ASIO 초기화에 실패하면 해당 실행에서는 WASAPI Shared로 자동 대체됩니다.

## 호환성

AVerMedia GC573에서 주로 개발·검증했습니다. 다른 DirectShow 캡처보드는
실험적으로 지원합니다.

- **영상:** progressive NV12 또는 YUY2. MJPEG는 실험적 호환 모드이며, P010 HDR10은 별도 실험 경로입니다.
- **오디오:** 영상 장치 또는 별도 DirectShow 입력의 48kHz 스테레오 PCM.
- **실험적:** P010 HDR10. 픽셀 포맷에서 직접 선택해야 하며, 장치가 신뢰할 수 있는 색공간 메타데이터를 제공할 때만 HDR 출력으로 사용합니다.
- **미지원:** H.264/AVC, MPEG-4, 자동 장치 재연결.

P010 경로는 `P010 10-bit HDR10 (실험적)`을 직접 선택했을 때만 활성화됩니다.
시작할 때 활성 DirectShow 형식, 일치하는 스트림 기능 항목, 실제 연결된 샘플 형식에서
BT.2020/PQ 메타데이터를 차례로 확인합니다. 기존 자동 선택은 계속 NV12/YUY2를 우선하며,
캡처 드라이버가 메타데이터를 제공하지 않으면 과포화를 막기 위해 BT.709 SDR 출력으로
전환합니다. HDR 경로는 실제 HDR 입력·HDR 모니터 조합에서 검증되지 않은
실험 기능입니다. HDR 입력임을 확인했는데도 DirectShow 색상 메타데이터가 없을 때는
고급 설정의 `P010 HDR10 강제` 옵션을 사용할 수 있습니다. 기본값은 끔이며, 켜면
P010을 BT.2020/PQ로 처리하므로 SDR 입력에서는 색상이 과포화될 수 있습니다.
프로토타입입니다.

선택한 해상도에서 30fps 이상의 NV12/YUY2가 없을 때만 MJPEG가 나타납니다.
또한 많은 캡처보드는 두 프로그램에서 동시에 열 수 없으므로 실행 전에 제조사
캡처 프로그램을 종료해야 합니다.

## 조작법

| 조작 | 기능 |
| --- | --- |
| `F2` | 뷰어를 안전하게 종료하고 설정 창 다시 열기 |
| `F3` | 오디오 미터 OSD 표시/숨기기 (L/R 레벨·dBFS·음량) |
| `F5` | 정확한 1:1 크기 복원. 캡처와 모니터 해상도가 같으면 전체화면 사용 |
| `F11` | 보더리스 전체화면 전환 |
| `Tab` | 실시간 정보창 표시/숨기기 |
| `Esc` | 자동 전체화면은 바로 종료. F11 전체화면은 먼저 창 모드로 전환 |
| 마우스 휠 | 앱 음량을 5% 단위로 조절 |
| `Shift` + 드래그 | 가장자리 스냅을 일시적으로 무시 |

채널별 음량을 조절하려면 `F3`으로 오디오 미터 OSD를 표시한 뒤 **L** 또는
**R** 카드 위에 마우스를 올리고 휠을 사용하세요. 한 번에 해당 채널만 5%씩
변경됩니다. 마스터 행이나 채널 카드 바깥에서 스크롤하면 마스터 음량이
변경됩니다. L/R 개별 음량은 100%까지이며, 선택적인 200% 증폭은 마스터
음량에만 적용됩니다.

**다음 실행부터 바로 시작**을 켜면 이후에는 설정 창을 건너뜁니다. 실행할 때
**Shift**를 누르거나 뷰어에서 **F2**를 누르면 설정 창을 다시 열 수 있습니다.

**업데이트 자동 확인**은 기본적으로 꺼져 있습니다. 켜면 시작 후 백그라운드에서
GitHub 최신 릴리스를 확인하고, 새 버전이 있을 때만 공식 설치 파일 다운로드를
묻습니다. 확인 작업은 영상·오디오 초기화와 별도 스레드에서 실행되며, 자동으로
설치하거나 실행하지 않습니다.
