LLCV v2.1.8 - dependencies
=========================

License: GNU General Public License v3.0 or later. See the root LICENSE file.

The x64 release is linked with the static MSVC runtime and does not require a
separate Visual C++ Redistributable installation. The target PC needs:

- Windows 10 or Windows 11 x64
- A DirectShow capture-card driver
- A card exposing NV12/YUY2/UYVY (HDYC)/MJPEG or P010 HDR10, and compatible 48 kHz
  mono/stereo PCM or 32-bit float audio, either on the video filter or as a
  separate DirectShow audio-input filter
- D3D11, DXGI, DirectShow, WASAPI, HID, SetupAPI, WIC, DWM and UxTheme Windows system components
- Optional console LPCM 5.1: explicit 48 kHz 6/8-channel PCM capture input and
  WASAPI Shared output. Configure Windows speakers for 5.1; stereo endpoints
  downmix. Dolby/DTS decoding and ASIO/Exclusive 5.1 are not supported.
- Optional ASIO mode: an ASIO-compatible output driver installed by the user.
  ASIO drivers are not included. The bundled Steinberg ASIO SDK host headers and
  helper sources are used under the SDK's GPLv3 option; see
  ASIO-SDK-LICENSE.txt in installed packages (third_party/asio/LICENSE.txt in
  source). Helper-source notices are included in ASIO-HOST-LICENSE.txt
  (third_party/asio/HOST-LICENSE.txt in source).

Device support depends on the formats exposed by its DirectShow driver. When
using UYVY/HDYC, the GPU/driver must support integer-texture reads, YUY2 UAV writes
and YUY2 video processing. UYVY/HDYC supports playback/screenshots, not recording.
When video and audio filters are separate, enable drift correction for
long sessions if the diagnostics show repeated imbalance.
No mpv.exe, third-party codec pack or companion executable is required.
Recording mux DLLs are included with the application.

Recording (v2.1.8)
------------------
H.264/HEVC/AV1 crash-tolerant MP4 storage uses a mux-only FFmpeg 8.1.3 build:
avformat-62.dll, avcodec-62.dll and avutil-60.dll. Encoding still uses the
installed Media Foundation hardware/software encoders. No FFmpeg program,
software AV1 encoder, decoder, network protocol, or third-party codec pack is
included. Release recordings use the packet muxer for all three codecs,
preserving color metadata and independently decodable segment boundaries.
MJPEG input decoding uses Windows Media Foundation, not a bundled FFmpeg decoder.
Build the pinned sources with tools/Build-RecordingFFmpeg.ps1 and configure
LLCV_RECORDING_FFMPEG_ROOT to its install directory. Source SHA256 and build
configuration are pinned in that script. Preserve the SDK's licenses directory
when distributing the application. FFmpeg source: https://ffmpeg.org/
The recording-OFF application does not link or load these libraries.

Settings typography
-------------------
Pretendard 1.3.9 TrueType Regular, Medium and SemiBold are embedded as private, process-local
fonts. They are not installed on the system. Licensed under SIL Open Font
License 1.1; see PRETENDARD-LICENSE.txt in packages or
third_party/pretendard/LICENSE.txt in source. Source and file hashes are recorded
in third_party/pretendard/SOURCE.txt.

Elgato driver/USB-protocol reference
------------------------------
The optional device tone-mapping request uses the published driver-property ABI
from elgatosf/capture-device-support (SampleCode/DriverInterface.cpp,
Library/ElgatoUVCDevice.cpp and Library/win/EGAVHIDImplementation.cpp), commit
fe9630974d47f51bf54826e72fb8b654e620aa93. No Elgato SDK or DLL is bundled/linked.
https://github.com/elgatosf/capture-device-support

Display upscaling
-----------------
NVIDIA Image Scaling 1.0.3 (MIT) and Intel CMAA2 (Apache-2.0).
Pinned source revisions, modifications and attribution: UPSCALING-NOTICE.txt.
Full licenses: NIS-LICENSE.txt and CMAA2-LICENSE.txt in installed packages;
third_party/upscaling/{nis/licence.txt,cmaa2/license.txt} in source.
Shaders are compiled into the normal executable. No external shader/source
files, runtime shader compilation, or private comparison algorithms are required.
