# 합성 글씨·계단현상 AA 비교

날짜: 2026-10-31
기준: 2.2.0, 로컬 `test/text-aa-comparison` 브랜치. 정식 필터·설정 변경 없음.

## 결론

- 이미 AA가 있는 합성 글씨에서는 NIS 단독이 목표 해상도 참조에 가장 가까웠다.
  현재 CMAA2를 추가하면 일부 획·모서리가 달라지는 현상을 재현했다.
- ExtraSharpness=1은 현재 방식보다 변형을 줄였지만 완전히 없애지 않았다.
  글자를 인식해 제외하거나 NIS 선명도를 추가로 높이는 옵션이 아니다.
- AA가 없는 사선에서는 CMAA2를 추가하면 NIS 단독보다 참조 오차가 줄었다.
  따라서 문자와 거친 3D 경계를 모두 만족하는 단일 승자는 확인하지 못했다.
- 이 결과는 특정 합성 자료에 한정된다. 실제 게임의 종합 화질 순위,
  시간적 깜빡임, 새 물리 지연 측정이나 HDR 개선 결과로 해석하지 않는다.

## 자료와 비교 조건

맑은 고딕의 일반·굵게·기울임 한글/숫자, 어두운/밝은 배경, 작은 글씨,
저대비 글씨, 1~3px 사선, 원·곡선과 반복 패턴을 직접 생성했다.
사진·생성형 이미지·게임 캡처를 새로 입력하지 않았다.

- 마스터: 7680×4320의 동일한 글리프/벡터 원본.
- 이미 AA가 있는 FHD 입력: 마스터의 4×4 면적 평균.
- 계단현상이 있는 FHD 입력: 마스터의 중앙 점 샘플링.
- 참조: 같은 마스터에서 QHD는 3×3, 4K는 2×2 면적 평균.
- 실제 테스트 입력: 1920×1080 회색조 NV12, BT.709 Limited.
  색차 서브샘플링의 영향을 배제하고 글씨·기하 형태에 집중했다.
- 필터 끔 / NIS 단독 / 현재 CMAA2→NIS / 보존형 CMAA2→NIS.
- NIS는 모두 0.15. CMAA2는 HIGH이며, 보존형만 ExtraSharpness를 0→1로 변경.
- NIS와 렌더러는 출시 라이브러리를 재사용했다. CMAA2 변형은 동일한 소스와
  매크로를 테스트 실행 파일에서만 컴파일했다.
- NIS 이전 입력·CMAA2 출력도 별도로 저장했다. 단계 분리 자료는 NIS를 거치지 않는다.

## 합성 참조와의 오차

어두운 배경 글씨 영역, 이미 AA가 있는 입력.
평균 절대 오차는 8비트 채널 단위이며 작을수록 이 참조에 가깝다.
화질 만족도나 일반 게임의 순위를 나타내는 점수는 아니다.

| 방식 | QHD 평균 절대 오차 | 4K 평균 절대 오차 |
| --- | ---: | ---: |
| 필터 끔 | 2.384 | 3.162 |
| NIS 단독 | 1.798 | 2.402 |
| 현재 CMAA2→NIS | 2.108 | 2.712 |
| 보존형 CMAA2→NIS | 1.897 | 2.508 |

QHD에서 AA가 없는 사선 영역은 NIS 단독 4.048, 현재 CMAA2 3.448,
보존형 3.508이었다. 문자 보존과 사선 보정 사이의 차이를 보여준다.

## GPU 처리 시간

RTX 3080. 각 입력·해상도·방식당 준비 4프레임 후 16회씩 3라운드,
총 48개 샘플. 라운드별 방식 순서를 뒤집었다.
표는 두 입력 조건의 평균값 범위이다.

| 방식 | QHD GPU ms | 4K GPU ms |
| --- | ---: | ---: |
| 필터 끔 | 0.582–0.599 | 0.614–0.637 |
| NIS 단독 | 0.749–0.776 | 0.895–0.925 |
| 현재 CMAA2→NIS | 0.906–0.944 | 1.064–1.116 |
| 보존형 CMAA2→NIS | 0.892–0.941 | 1.082–1.103 |

타임스탬프는 업로드·처리·출력 의존성을 포함한 진단용 GPU 구간이다.
Present와 실제 캡처 장치는 사용하지 않았다. 이 수치를 입력→표시 지연으로
읽거나 작은 평균 차이를 속도 우열로 단정하지 않는다.
진단용 readback·동기 대기는 이 테스트에만 있으며 제품 경로에 추가하지 않았다.

## 검증

4개 방식 × 2개 입력 조건 × 2개 출력 해상도 = 16개 출력 조합을 확인했다.

- 테스트가 실제 설정과 분리된 임시 프로필을 사용하는지 확인.
- 진짜 NIS 단독 경로와 현재 경로에서 분리한 NIS 단계의 출력 일치.
- 현재 매크로로 재컴파일한 CMAA2와 내장 출시 셰이더가 채널 오차 1 이내로 일치.
- 모든 CMAA2 자료에서 오버플로 우회가 없음을 확인.
- 반복 방식 전환 뒤 출력이 채널 오차 1 이내로 안정적.
- 입력 버퍼 보존, 필터 끔 복원은 완전 일치.
- CmaaNisRegression, CmaaNisHdr, CmaaNisRgb, CmaaNisRecording,
  UpscalingSafetyHardware, UpscalingSafetyWarp, TestProfileTests: 7/7 통과,
  실패·건너뜀 0, 21.91초.
- 일반 앱 EXE와 출시 업스케일링 라이브러리 SHA256은 작업 전후 동일.
- 실제 재생·녹화 설정 SHA256은 작업 시작 시 값과 동일. 이전 작업 때의 설정을
  덮어쓰거나 가져오지 않았다.

전체 199개를 다시 실행한 결과로 표현하지 않는다. 정식 소스·필터·기본값을
바꾸지 않은 수동 비교 및 관련 회귀 실행이다.

## 재현

기존 녹화 의존성이 설정된 x64 Release 테스트 빌드에서:

```powershell
cmake --build build-v2200-release --target CmaaNisTests --parallel 4
.\build-v2200-release\CmaaNisTests.exe --text-fixture .\third_party\upscaling\cmaa2\CMAA2.hlsl outputs\text-aa-study\new-comparison
```

출력 폴더는 새 경로여야 한다. 실제 장치나 사용자 설정 파일을 지정하지 않는다.

최종 자료: `outputs/text-aa-study/final-1793436547674/`.
`comparison.html`에서 같은 위치를 전환하며 QHD·4K와 글씨·사선·곡선을 볼 수 있다.
`metrics.csv`, `gpu-times.csv`, `method.txt`와 PNG 전체/글씨 크롭을 보존했다.
작업 로그: `outputs/text-aa-study/{build-final,comparison-final,related-regression}.log`,
`related-regression.xml`. 앞선 regular-only 시안은 최종 결과와 합산하지 않는다.
