# CMAA2 HIGH와 보존형 지연 비교

2026-10-31. 2.2.0 기반 별도 테스트 도구, RTX 3080 / AVerMedia GC573.
둘 다 HIGH, NIS 0.15. CMAA2 ExtraSharpness 0(기존) / 1(보존형)만 비교했다.
정식 옵션·기본값·렌더 소스·실제 설정을 변경하지 않았다.

## 결론

- GPU 처리 구간 차이는 입력·출력 조건별 약 -0.007~+0.006ms.
  두 방식의 반복 범위가 겹친다. 안정적인 속도 우위는 확인하지 못했다.
- 창모드 표시 지연 평균은 기존 13.722ms, 보존형 12.340ms였다.
  그러나 짝지은 실행 한 번은 보존형이 1.019ms 더 높았고 반복 범위도 겹친다.
  평균 -1.382ms를 보존형의 고정 개선 효과로 주장하지 않는다.
- 이번 조건에서 보존형으로 인한 추가 지연은 확인되지 않았다.
  화질 선호로 선택할 수 있는 수준의 처리 비용 차이였다.

## GPU 처리 구간

동일한 FHD NV12 SDR / BT.709 Limited 원본. 저장된 게임 정지 화면과
기존 합성 경계 패턴을 각각 QHD/4K로 처리했다.
두 방식 모두 동일 소스·컴파일 옵션으로 컴파일하고 ExtraSharpness만 바꿨다.
기존 변형과 출시 내장 출력의 픽셀 오차 최대 1 이내 및 AA 오버플로 우회 없음 확인.

6회 교차 AB/BA, 방식별 매회 최소 500ms 연속 부하 준비 후 120프레임,
조건·방식별 720개, 총 5760개 타임스탬프. 준비 구간 끝에서 출력을 읽어 완료를
확인한 후 측정한다. 측정 중 별도 GPU 테스트·실기 표시 측정은 겹치지 않았다.
구간은 업로드·VP·CMAA2·NIS 및 출력 의존성 복사를 포함한다.
Present/캡처보드/디스플레이는 사용하지 않는다.

| 입력 | 출력 | 기존 HIGH 평균 (반복 범위), ms | 보존형 평균 (반복 범위), ms |
| --- | --- | ---: | ---: |
| 저장 게임 | QHD | 0.8963 (0.8882–0.9073) | 0.8894 (0.8830–0.9065) |
| 저장 게임 | 4K | 1.0966 (1.0879–1.1113) | 1.1030 (1.0877–1.1292) |
| 합성 경계 | QHD | 0.9337 (0.9232–0.9493) | 0.9386 (0.9353–0.9411) |
| 합성 경계 | 4K | 1.1105 (1.1014–1.1219) | 1.1150 (1.1045–1.1395) |

초기 프레임 사이 대기 방식은 GPU 절전 변동이 크게 섞였다. 종료 후 P8,
그래픽 210MHz/메모리 405MHz 상태도 관측했다. 해당 `gpu/` 자료는 보존하지만
비용 우열 판단에 합산하지 않았다. 본 표는 연속 부하의 `gpu-steady/`만 사용한다.
이는 60fps 실기 상태의 GPU 클럭이나 입력→표시 지연을 뜻하지 않는다.

## 실제 표시 경로

- 사용자 준비 후 NV12 1920×1080, 60fps, SDR 캡처와 QHD 창모드 출력을 로그로 확인.
- 입력 스냅샷은 콘솔 홈 화면이었다. 움직이는 게임의 화질·복잡도 검증으로 표현하지 않는다.
- 같은 앱 공통 오브젝트를 두 EXE에 연결하고 CMAA 셰이더 라이브러리만 다르게 연결했다.
  기존 셰이더는 출시 라이브러리, 보존형은 동일 fxc 옵션에서 ExtraSharpness=1.
- 두 EXE는 컴파일 단계에서 TestProfile 격리. 실제 설정을 읽거나 가져오지 않는다.
- 기존→보존 / 보존→기존 순서를 각각 두 번, 총 8회 실행.
  매회 최초 3초·마지막 0.5초 제외. Present QPC와 앱 기록을 최대 0.25ms로 대응.
- 모든 분석 이벤트 Composed: Flip. 독점 전체화면·직접 표시 비교가 아니다.
- PresentMon은 권한 경고를 남겼으나 대상 PID의 기록이 실제로 수집됐고
  분석 대상 대응 실패 0건. 경고가 없었다고 표현하지 않는다.

실행 평균을 같은 가중치로 평균했다. 범위는 신뢰구간이 아니다.
표시 지연은 캡처 콜백 도착→Windows 표시 이벤트이며 HDMI 전송·캡처보드 내부·
모니터 스캔아웃/응답까지의 광학 측정이 아니다. 누락 0은 이 분석 구간에 한정된다.
