# LLCV v2.2.1

## 한국어

- **CMAA2 보정 선택:** SDR 업스케일링에서 높음·보존형을 고를 수 있습니다. 높음은 경계를 더 적극적으로 보정하고, 보존형은 글씨·얇은 선의 원래 형태를 더 유지합니다.
- **HDR10 업스케일링:** P010 HDR10은 NIS로 확대하며, 원본 보간 영상 기준으로 과한 윤곽 변화를 제한합니다. CMAA2는 실행하지 않고 SDR용 보정 선택은 유지합니다. HDR 녹화가 추가된 것은 아닙니다.
- **설정 UI:** CMAA2 보정과 NIS 선명도를 나란히 배치하고 간격·정렬을 다듬었습니다. 스크린샷 설정은 앱 설정으로 옮겼으며 Tab·Shift+Tab 이동 순서도 실제 배치에 맞췄습니다.
- **릴리스 노트 바로가기:** 앱 설정의 업데이트 영역에서 현재 버전의 GitHub 릴리스 노트를 브라우저로 열 수 있습니다.

[업스케일링 안내](USAGE.ko.md#cmaa2--nis-업스케일링) · [앱 설정](USAGE.ko.md#설정-찾기)

## English

- **CMAA2 correction:** choose High or Preserve for SDR upscaling. High smooths more edges; Preserve retains more of the original text and thin-line shape.
- **HDR10 upscaling:** P010 HDR10 uses NIS with an original-reference contour bound. CMAA2 is skipped while its saved SDR correction preference is retained. This does not add HDR recording.
- **Settings UI:** place CMAA2 correction and NIS sharpness side by side and refine spacing/alignment. Move screenshot preferences to App settings and align Tab/Shift+Tab traversal with the page layout.
- **Release notes shortcut:** open the current version's GitHub release notes in a browser from the Updates area in App settings.
