# 저지연 오디오

> [English](AUDIO.md) · [README로 돌아가기](../README.ko.md)

## 캡처 오디오 선택

자동 선택은 먼저 영상 캡처 필터 안에서 48kHz 스테레오 PCM 오디오 핀을
찾습니다. USB 캡처보드가 오디오를 별도 DirectShow 입력으로 제공하면 이름이
일치하는 장치를 자동으로 연결합니다. 자동 연결이 맞지 않을 때는 대응하는 오디오
입력을 직접 선택하세요.

서로 다른 필터에서 들어오는 영상과 오디오는 하드웨어 클록이 조금씩 다를 수
있습니다. 장시간 사용하면 이 차이로 PCM 대기량이 목표에서 벗어날 수 있습니다.
같은 클록을 쓰는 장치에서는 보정이 보통 필요하지 않지만, USB 영상·오디오 경로가
분리된 경우에는 도움이 될 수 있습니다.

## 콘솔 LPCM 5.1 (실험적 · v1.2.10부터)

오디오 탭에서 **WASAPI Shared**를 선택하고 **콘솔 LPCM 5.1**을 켭니다.
기본값은 꺼짐이며, Exclusive와 ASIO에서는 이 옵션이 적용되지 않습니다.

- 콘솔은 **5.1 LPCM**으로 설정하세요. Dolby/DTS 비트스트림 디코딩이나 가상
  서라운드는 제공하지 않습니다.
- 캡처 장치가 PC에 **48kHz 6채널 또는 8채널 PCM**을 제공해야 합니다.
  HDMI 패스스루의 5.1 지원만으로는 충분하지 않습니다.
- 실제 5.1 재생에는 Windows 출력 장치의 스피커 구성도 5.1이어야 합니다.
  스테레오 출력 장치로 바꾸면 Windows 공유 엔진이 다운믹스합니다.
- 6채널 입력은 센터와 LFE를 포함해 그대로 전달합니다. 8채널 입력은 뒤·옆
  서라운드를 각각 -3dB로 합쳐 5.1로 출력합니다. 채널 배치 정보가 없거나
  지원하지 않는 배치면 추측해서 재생하지 않고 초기화를 중단합니다.
- 마스터 음량과 음소거는 모든 채널에 적용됩니다. L/R 조절은 각 방향의
  앞·서라운드에 적용하며 센터와 LFE는 마스터만 따릅니다. L/R 미터에는
  센터/LFE도 포함되며 개별 6채널 미터는 아닙니다.
- 출력 형식에 따라 Shared 호환 경로가 사용될 수 있습니다. Tab 진단에서 실제
  출력 버퍼를 확인하세요. 기존 PCM 목표나 클록 보정 설정은 그대로 사용합니다.

실제 캡처·출력 장비에서 채널별 청취 검증은 아직 완료되지 않았습니다.
콘솔의 스피커 테스트로 센터·서라운드·LFE 위치를 확인하고, 문제가 있으면
진단 로그를 함께 전달해 주세요. 시험 중 다른 캡처 앱을 동시에 열지 마세요.
실행 중 입력 채널 수나 형식이 바뀌면 재생을 중단하고 설정으로 돌아갑니다.
콘솔의 오디오 설정을 먼저 확정한 뒤 다시 시작하세요.

## 오디오 only 모드

설정의 **오디오 only 모드**를 켜면 비디오 핀, D3D11 렌더러와 화면 표시를
건너뛰고 캡처 오디오→선택한 오디오 출력만 실행합니다. 오디오 입력이 영상 장치 내부
핀에 있으면 해당 영상 장치 필터에서 오디오 핀만 연결하고, 별도 오디오 장치를
선택한 경우에는 그 DirectShow 오디오 필터만 사용합니다. WASAPI 모드, PCM 목표와
클록 드리프트 보정은 일반 모드와 동일하게 조정할 수 있습니다. 별도의 오디오
전용 화면에서 마스터·L/R 음량, 출력 레벨(dBFS), 클리핑 상태를 보여 줍니다.
마스터 또는 L/R 영역 전체에서 휠로 음량을 조절하고, 두 번 클릭하면 해당 음량을
100%로 되돌립니다. 제목·하단 안내·영역 사이의 여백에서는 음량이 바뀌지 않습니다.
100% 이상 볼륨 증폭을 허용하면 마스터 영역에 **최대 200%**가 표시되고,
현재 마스터 음량이 100%를 넘을 때 숫자가 주황색으로 바뀝니다. 이는 증폭 표시이며,
실제 클리핑 여부는 하단 상태에 별도로 표시합니다.
**제목 표시줄 숨기기**를 켜면 오디오 전용 창도 보더리스로 열립니다.
마스터·L/R을 포함해 화면 어디서든 드래그하여 창을 이동할 수 있습니다.
가장자리를 끌면 고정 비율로 크기를 조절합니다. 마스터·L/R에 마우스를 올리면 해당 영역이 강조되며, 강조된 영역에서도 드래그로 창을 이동할 수 있습니다.
최소 창 크기는 Windows 화면 배율에 맞춰 조정되어, 작은 창에서도 글자와 조작 영역을 유지합니다.

## WASAPI Shared와 Exclusive

**WASAPI Shared**는 다른 프로그램도 출력 장치를 함께 사용할 수 있고 Windows의
Shared 모드 효과를 유지합니다. 기본 권장 방식입니다.

출력 장치가 `IAudioClient3`를 지원하면 유효한 Shared 엔진 주기를 읽고, 요청값과
가장 가까운 저지연 주기로 `InitializeSharedAudioStream` event-driven 출력을
시작합니다. 설정 창에는 지원 범위가, Tab 정보창에는 실제 적용 주기가 표시됩니다.

해당 장치나 포맷에서 `IAudioClient3`를 쓸 수 없으면 기존 WASAPI Shared로
자동 대체됩니다. 이는 정상적인 호환 경로이며 초기화 실패가 아닙니다.

**WASAPI Exclusive**는 출력 장치를 직접 엽니다. 공유 믹서 경로를 줄일 수 있지만
다른 프로그램이 해당 장치를 동시에 쓰지 못할 수 있습니다. Equalizer APO,
HeSuVi, Windows 공간 음향처럼 Shared 모드에 적용되는 APO/DSP도 우회할 수
있습니다. 이런 효과나 일반적인 호환성이 필요하면 Shared를 사용하세요.

Exclusive는 앱이 출력 장치별 실제 재생 이벤트 사전 검사를 통과시킨 경우에만
선택할 수 있습니다. 출력 장치 목록에는 `사용 가능 · n ms`, `사용 불가`, `검사 중`
상태가 표시되고 결과는 장치 ID별로 저장됩니다. 초기화는 받아들이지만 실제 이벤트
타이밍이 불안정한 드라이버를 미리 걸러내기 위한 검사입니다. 통과했다고 모든 상황을
보장하는 것은 아니므로 문제가 남으면 Shared 또는 ASIO로 전환하고 로그를 첨부하세요.

## ASIO (실험적)

ASIO는 설정 창에서 설치된 ASIO 드라이버가 감지될 때만 선택지로 나타납니다.
드라이버 DLL은 배포하지 않으며, 선택한 드라이버의 기본 버퍼 크기를 그대로
사용합니다. 캡처 PCM이 48kHz이므로 48kHz를 지원하지 않는 드라이버는 시작하지
않고 해당 실행에서 WASAPI Shared로 대체됩니다. 이 프로토타입은 ASIO 드라이버
출력 클록을 직접 사용하지만, WASAPI와 같은 앱 클록 드리프트 보정의 끔/자동/켬을
지원합니다. 켜면 리샘플러가 별도 대기열을 추가하지 않고 캡처 PCM 속도만 미세
조정합니다. Windows APO/DSP가 필요하면 WASAPI Shared를 사용하세요.

## 출력 장치 전환

**Windows 기본 출력 장치 따라가기**를 사용하면 앱 실행 중 Windows 기본 장치를
바꿔도 영상 캡처를 유지한 채 WASAPI 출력만 다시 엽니다. 전환에 걸린 시간이
누적 재생 지연으로 남지 않도록 기존 PCM을 비우므로 짧은 무음이나 작은 클릭이
생길 수 있습니다.

Windows 기본 장치가 바뀌어도 항상 같은 장치로 출력해야 한다면 특정 출력 장치를
고정해서 선택하세요.

## WASAPI 버퍼와 PCM 목표

세 설정은 서로 다른 부분을 조절합니다.

- **WASAPI 출력 버퍼:** 출력 장치에 요청하는 period 또는 버퍼
- **PCM 버퍼 목표:** 캡처와 재생 사이의 앱 내부 안전 대기량
- **클록 드리프트 보정:** 장시간 샘플 속도 차이를 조절하며 위 두 버퍼를 대신하지 않음

새 설치의 PCM 목표는 25ms입니다. 이전 버전의 20ms 저장값만 처음 실행할 때
한 번 25ms로 바꾸며, 다른 값은 유지합니다. 이후 직접 20ms를 고르면 그대로 유지됩니다.
시스템이 안정적인 것을
확인한 뒤 더 낮은 지연이 필요할 때만 `25 → 20 → 15 → 10ms` 순서로 시도하세요.
너무 낮은 목표에서 underrun이 반복되면
15/20/25/30ms로 다시 올리는 것이 좋습니다. 목표를 높이면 스케줄링 여유가 늘지만 그만큼
오디오 대기 지연도 늘어납니다. 가끔 한 번 발생한 underrun은 반드시 들리는 문제이거나
버퍼를 올려야 한다는 뜻은 아닙니다.

로그에 표시되는 DirectShow allocator는 캡처 드라이버의 영향도 받습니다. 블록
크기나 개수가 앱이 실제로 쌓아 두는 오디오 양과 같지는 않습니다.

## 클록 드리프트 보정

**끔**은 PCM 샘플을 변경하지 않습니다. 기본값인 **자동**은 PCM 대기량을 관찰하다가
불균형이 5초 이상 지속될 때만 보정을 시작하며, 한 번 시작하면 같은 세션에서
반복해서 켰다 끄지 않습니다. **켬**은 시작부터 항상 리샘플러를 사용합니다.
장시간 사용 후 소리가 반복적으로 끊기거나 PCM 대기량 불균형이 한 방향으로
계속 커질 때, 특히 영상과 오디오가 별도 캡처 필터에서 들어올 때 자동을 선택하세요.

보정은 PCM 대기량을 목표 부근에 유지하도록 샘플 속도를 아주 작게 연속 조절합니다.
별도 프레임이나 패킷 대기열을 의도적으로 추가하지 않습니다. 시작 직후나 순간적인
스케줄링 지연은 ppm 추정값을 왜곡할 수 있으므로 Tab 정보창을 10~30분 관찰한 뒤
판단하는 것이 좋습니다.

## 음량과 백그라운드 음소거

마우스 휠은 음량을 5% 단위로 바꿉니다. 100%에서는 PCM 볼륨 연산을 건너뜁니다.
**100% 이상 볼륨 증폭 허용**을 켜면 버퍼를 추가하지 않고 최대 200%까지 디지털
증폭하지만 큰 신호는 클리핑될 수 있습니다.

채널별 음량을 조절하려면 영상 모드에서 `F3`으로 오디오 미터 OSD를 표시하거나
오디오 전용 화면에서 **L** 또는 **R** 카드 위에 마우스를 올리고 휠을 사용하세요.
해당 채널만 5% 단위로 변경됩니다. 마스터 영역이나 채널 카드 바깥에서 스크롤하면 마스터 음량이
변경됩니다. L/R 개별 게인은 100%로 제한되며, 선택적인 200% 증폭은 마스터
음량에만 적용됩니다.

백그라운드 자동 음소거는 출력 게인만 변경합니다. 창이 비활성화되어도 캡처와
WASAPI 소비는 계속되므로 다시 돌아왔을 때 PCM 누적 지연이 생기지 않습니다.
