# 프레임 보간

[README](../README.md) · [사용 가이드](USAGE.ko.md) · [English](FRAME_INTERPOLATION.md)

캡처 원본 두 장 사이에 중간 화면을 넣어 재생 움직임을 부드럽게 합니다. 게임의 원래 프레임이나 조작 반응이 빨라지는 기능은 아닙니다. 화면 재생에만 적용되며 녹화와 원본 스크린샷에는 들어가지 않습니다.

| 방식 | 캡처 입력 | GPU 및 구성품 |
| --- | --- | --- |
| NVIDIA VFG | FHD·QHD·4K UHD SDR, 24~60fps | 공식 VFG를 지원하는 Windows x64 NVIDIA Ada·Blackwell GPU와 호환 NVIDIA 런타임 |
| RIFE Vulkan | FHD SDR, 24~60fps · 저지연 출력 | Vulkan을 사용할 수 있는 재생 GPU · Fast 모델 동봉 |

- **설정 → 프레임 보간**에서 사용을 켜고 RIFE Vulkan 또는 NVIDIA VFG를 선택합니다. 새 설정에서는 보간이 꺼져 있고 방식은 RIFE Vulkan으로 선택되어 있습니다. 기존 VFG 설정은 유지되며, 선택한 방식은 자동으로 바뀌지 않습니다.
- RIFE Vulkan은 별도 다운로드가 필요 없습니다. HUD 보호는 기본적으로 밝기와 색 윤곽을 사용하며, 밝기 윤곽만 사용하거나 끌 수도 있습니다.
- RIFE가 준비되는 동안에는 원본이 계속 재생됩니다. 준비에 실패하거나 입력을 지원하지 않으면 원본 재생을 유지합니다. 장치 오류에서 복구된 뒤에는 F7로 껐다 켜서 다시 시도할 수 있습니다.
- RIFE Vulkan은 NV12, YUY2, UYVY/HDYC, RGB24, XRGB(RGB32), MJPEG를 지원합니다. 저지연으로 시작하면 선택한 픽셀 포맷은 유지하면서 FHD로 캡처합니다. P010 HDR은 보간하지 않으며 캡처 해상도도 바꾸지 않습니다.
- RIFE 사용 시 영상 탭의 프레임에서 자동 또는 장치가 제공하는 24~60fps를 선택할 수 있습니다. RIFE 없이 시작하면 기존 캡처 프레임 설정을 사용합니다.
- 영상 탭에는 적용될 입력을 표시합니다. 표시 해상도와 저장된 영상 설정은 유지되며, 다른 방식으로 바꾸거나 보간 사용을 끄면 저장된 입력이 다시 표시됩니다. F7은 캡처 연결을 바꾸지 않습니다.
- VFG는 저지연(일반 출력), VSync, 독점 전체화면에서 사용할 수 있습니다. 재생 중 F7로 바꾼 켜기/끄기 상태는 F2로 설정을 열거나 앱을 다시 시작해도 유지되며, 사용 체크는 바뀌지 않습니다.
- VSync에서는 모니터 주사율이 캡처 FPS의 두 배 이상이어야 합니다(예: 30fps → 60Hz, 60fps → 120Hz). 주사율이나 표시 준비 신호가 부족하면 원본으로 재생합니다. 호환성 출력(Blt)은 지원하지 않습니다.
- Ada·Blackwell은 NVIDIA 기본 경로를 사용합니다. RTX 30(SM 8.6)은 지정된 런타임에서만 시도하는 실험적 호환이며, RTX 3080에서 검증했습니다. NVIDIA 공식 지원이나 모든 RTX 30 모델의 동작을 보장하지 않습니다.
- **Tab 진단**에서 생성·기한 초과 횟수를 볼 수 있습니다. 기한을 놓치면 원본을 표시합니다. 높은 해상도·FPS에서 모든 중간 프레임 생성은 보장하지 않습니다.
- **F**는 재생 FPS만 표시합니다. 이 값에는 화면에 제출한 보간 프레임이 포함됩니다.
- VFG 첫 사용 시 **설정 → 프레임 보간 → VFG 구성품 받기**를 누릅니다. 확인하면 [NVIDIA 공개 패키지 서버](https://pypi.nvidia.com/nvidia-vfx/)에서 고정 버전(약 416 MiB)을 받아 검증 후 현재 Windows 사용자 폴더에 설치합니다. 로그인과 관리자 권한은 필요하지 않습니다. 기본 설치판에 NVIDIA DLL이나 VFG 모델은 동봉하지 않습니다.
- 다운로드나 검증에 실패하면 원본 재생은 계속됩니다. 같은 버튼으로 다시 시도할 수 있습니다. 일반 재생이나 F7로는 다운로드하지 않습니다.
- **영상 → 재생 그래픽카드**에서 원하는 GPU를 선택하고 시작을 누릅니다. 자동은 외장 GPU를 우선합니다. 독점 전체화면에서는 표시 모니터가 연결된 GPU를 사용하며, 지정한 GPU를 사용할 수 없으면 다른 GPU로 재생을 시도합니다. VFG는 실제 재생 GPU가 호환될 때만 작동합니다. F7은 GPU를 바꾸지 않습니다.
