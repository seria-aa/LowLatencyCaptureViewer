# 호환성 출력 비교 안내 — v1.2.7

v1.2.7에 추가된 선택 옵션입니다. 기본값은 기존 저지연입니다.

1. 압축을 별도 폴더에 풀고 실행합니다. 설정 없이 바로 시작되면 F2로 설정을 엽니다.
2. **영상·창 → 화면 표시 방식 → 호환성 출력 (Blt · VSync)**를 선택하고 시작합니다.
3. Tab 정보창의 표시 줄에서 **Blt-discard · VSync**를 확인합니다.
4. 같은 캡처·오디오·전체화면 설정으로 기존 VSync와 비교합니다. 이전 증상이 발생하던
   시간보다 충분히 길게 사용하고, 표시 상태·발생 시각·체감 지연을 함께 알려주세요.
5. 문제가 있으면 **단축키·진단 → 진단 로그 파일 저장**을 켜고 재현한 뒤,
   **로그 폴더 열기**에서 해당 실행의 로그를 전달해 주세요.

기존 저지연/VSync는 Flip-discard를 그대로 사용합니다. 호환성 출력만 Blt-discard와
VSync를 사용하며 지연·GPU 부하가 늘 수 있습니다. 캡처와 오디오 버퍼는 변경하지
않습니다. HDR10 출력과는 함께 사용할 수 없습니다. P010 HDR 입력은 기존 경로를 쓰세요.

비교 전 설정값을 기록해 두고, 효과가 없으면 화면 표시 방식을 원래 값으로 되돌려 주세요.
표시 모니터 선택은 시작 위치만 정합니다. 모니터나 GPU 출력 경로를 고정하는 기능은 아닙니다.
