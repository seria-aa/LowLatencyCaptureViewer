# 문제 해결

> [English](TROUBLESHOOTING.md) · [README로 돌아가기](../README.ko.md)

## 캡처 초기화 실패

OBS Studio, 제조사 캡처 프로그램, 브라우저, 화상 통화 앱, 가상 카메라 도구 등
캡처보드를 사용하고 있을 수 있는 프로그램을 모두 종료하세요. 일부 드라이버는
장치가 사용 중이라는 설명 대신 시스템 리소스 오류를 반환합니다.

그다음 아래 순서로 확인하세요.

1. USB 캡처보드는 다시 연결하고, PCIe 장치는 PC를 재시작합니다.
2. 입력 기기가 지원되는 progressive 해상도와 프레임을 출력하는지 확인합니다.
3. 자동 선택 대신 캡처 장치를 직접 선택합니다.
4. 자동/NV12, YUY2, 목록에 있다면 MJPEG 순서로 시험합니다.
5. 장치가 지원하는 더 낮은 해상도 또는 프레임을 시험합니다.
6. 진단 로그 파일 저장을 켜고 마지막 초기화 단계를 확인합니다.

`0x800705AA`는 Windows가 시스템 리소스 부족을 보고했다는 뜻입니다. 캡처보드에서는
다른 프로그램이나 제조사 서비스가 장치를 점유했거나 드라이버가 요청한 allocator를
거부했을 때도 나타날 수 있습니다.

`0x80070490`은 필요한 요소를 찾지 못했다는 뜻입니다. 요청 모드가 실제로 없거나,
호환되는 캡처 핀을 찾지 못했거나, 48kHz 스테레오 PCM 오디오 경로가 없는 경우가
대표적입니다. 오류 코드만 보는 것보다 로그의 실패 단계와 핀 진단이 중요합니다.

## 영상은 나오지만 소리가 없음

일부 USB 캡처보드는 영상과 오디오를 별도 DirectShow 필터로 제공합니다. **캡처
오디오 장치**에서 같은 USB 장치의 오디오 입력을 직접 선택하세요. 입력은 48kHz
스테레오 PCM을 제공해야 합니다.

별도 필터를 선택한 상태에서 장시간 사용한 뒤에만 소리가 끊긴다면 Tab 정보창의
PCM 추세를 관찰하고 클록 드리프트 보정을 시험하세요. 실행 직후부터 underrun이
반복된다면 먼저 PCM 목표를 한 단계 올리는 편이 맞습니다.

## 화면이 흐림

Pixel-perfect는 캡처 해상도를 그대로 사용할 수 있을 때 정확한 1:1 화면을
제공합니다. 크기가 바뀐 창이나 전체화면에서는 **선명하게**를 시험하세요. 지원되는
D3D11 Video Processor의 가장자리 보강을 사용하며 프레임 큐를 추가하지 않습니다.
드라이버가 지원하지 않으면 부드럽게로 자동 대체됩니다.

입력 기기의 출력 해상도와 캡처 해상도도 확인하세요. 1440p 입력을 4K로
캡처한다고 원본 세부 정보가 늘어나지는 않습니다.

## 프레임 드랍 또는 끊김

Tab 정보창에서 입력 FPS가 선택한 소스 속도와 맞는지, Present FPS가 이를
따라가는지 확인하세요. YUY2나 MJPEG보다 NV12를 먼저 시험하고, 장치나 USB 연결이
현재 모드를 감당하지 못하면 해상도 또는 FPS를 낮춰 보세요.

서로 다른 주사율의 모니터와 Windows DWM 합성 때문에 창 모드 페이싱이 달라질
수 있습니다. 실제 사용할 모니터에서 저지연과 VSync를 비교하세요.

## 설정 창을 건너뜀

**다음 실행부터 바로 시작**이 켜져 있다면 실행할 때 Shift를 누르세요. 뷰어에서
`F2`를 눌러 안전하게 종료하고 설정 창으로 돌아갈 수도 있습니다.

## 문제 제보에 필요한 정보

**진단 로그 파일 저장**을 켜고 문제를 한 번 재현한 뒤 아래 폴더의 최신 파일을
첨부하세요.

```text
%LOCALAPPDATA%\LowLatencyCaptureViewer\logs
```

캡처보드 모델, 입력 해상도/FPS, 선택 포맷, 캡처 오디오 장치, 출력 장치,
Windows 버전과 다른 캡처 프로그램을 실행했는지도 함께 알려주세요.
