# LLCV v2.1.7

## 한국어

- **F6 업스케일링 전환:** 선택한 CMAA2 → NIS 또는 NVIDIA VSR을 그대로 켜고 끕니다. 방식과 NIS 선명도는 껐다 켜도 유지하며, 단축키 안내와 OSD도 선택한 방식에 맞게 표시합니다. 기존에 VSR이 켜져 있던 설정은 유지하고, 선택 이력이 없으면 F6으로 CMAA2 → NIS(기본 선명도 0.15)를 켭니다.
- **업데이트 후 첫 실행:** 바로 시작을 켜두었어도 업데이트 후에는 설정 창을 한 번 보여줍니다. 기존 바로 시작 선택은 바꾸지 않으며, 설정 창을 닫은 뒤 다음 실행부터 다시 적용합니다.

[사용 가이드](USAGE.ko.md) · [영상 설정](VIDEO.ko.md) · [녹화 안내](RECORDING.ko.md)

## English

- **F6 upscaling toggle:** turns the selected CMAA2 → NIS or NVIDIA VSR method on and off without switching methods or resetting NIS sharpness. Shortcut help and OSD now match the selected method. Previously enabled VSR settings are retained; with no selection history, F6 enables CMAA2 → NIS with default sharpness 0.15.
- **First launch after an update:** shows settings once even when Start directly is enabled. The saved preference is unchanged and applies again on the next launch after closing settings.
