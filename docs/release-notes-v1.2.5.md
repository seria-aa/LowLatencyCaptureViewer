## v1.2.5

### 한국어

- 설정 탭 이름을 **안내 · 진단**에서 **단축키 · 진단**으로 변경해 탭의
  내용을 더 쉽게 알 수 있도록 했습니다.
- 단축키 목록에 누락됐던 `F11` 보더리스 전체화면 전환 안내를 추가했습니다.
- 안내 탭을 열지 않아도 확인할 수 있도록 영상·창 탭의 전체화면 커서 옵션
  아래에 F11 안내를 우측 정렬로 추가했습니다.
- Pixel-perfect 체크 상태를 바꿔 창 옵션 배치가 다시 계산되어도 F11 안내가
  콤보박스에 덮여 사라지지 않도록 수정했습니다.
- 한국어·영문 README와 진단 문서의 탭 명칭을 함께 갱신했습니다. 캡처,
  렌더링 및 오디오 처리 경로는 변경하지 않았습니다.

### English

- Renamed the **Guide & diagnostics** settings tab to **Shortcuts &
  diagnostics** so its contents are immediately clear.
- Added the missing `F11` borderless-fullscreen shortcut to the shortcut list.
- Added a right-aligned F11 hint below the fullscreen-cursor option in the
  Video & window tab so the shortcut is visible without opening the guide.
- The hint now remains visible when a Pixel-perfect change relayouts the
  surrounding window options instead of being painted over by the combo box.
- Updated the Korean and English README and diagnostics documentation to use
  the new tab name. Capture, rendering, and audio processing paths are
  unchanged.
