Low Latency Capture Viewer v1.1.0 실행 안내
=======================================

1. GC573 또는 지원할 캡처 장치를 연결합니다.
2. 사용할 헤드폰/스피커를 연결합니다.
3. LowLatencyCaptureViewer.exe를 실행합니다. 다른 실행 파일은 필요 없습니다.
4. 출력 장치, 캡처 장치, 해상도, 픽셀 포맷과 창 설정을 고른 뒤 시작을 누릅니다.
- `다음 실행부터 바로 시작`을 켜면 이후에는 저장된 설정으로 곧바로 영상 창을 엽니다. Shift를 누른 채 실행하면 그 한 번만 설정 창을 열고, 실행 중 F2를 누르면 안전하게 종료한 뒤 설정 창을 다시 엽니다.
- 설정 창은 마우스가 있는 모니터 중앙에서 열리며, Windows 배율과 모니터 해상도가 달라도 기본 950x510 DIP / 고급 950x640 DIP 레이아웃과 글꼴 비율을 유지합니다.
- 설정 창을 배율이 다른 모니터로 옮겨도 창, 글꼴과 컨트롤이 같은 DPI 기준으로 함께 조정됩니다.

v0.15 장치와 로그 설정
- WASAPI 출력 장치: Windows 기본 출력 장치 따라가기(권장) 또는 특정 활성 출력 장치를 고릅니다.
- 기본 장치 따라가기는 앱 실행 중 Windows 기본 출력이 바뀌면 WASAPI만 다시 열어 새 장치로 전환합니다. 영상은 계속 실행되며 전환 순간 짧은 무음이나 작은 클릭이 생길 수 있습니다.
- 새 출력 장치가 준비된 직후 PCM 대기분을 비우므로 장치를 여러 번 바꿔도 장치 초기화 시간이 PCM 버퍼 지연으로 누적되지 않습니다.
- 특정 장치를 고르면 Windows 기본 출력이 바뀌어도 선택 장치를 계속 사용합니다.
- 캡처 장치: 자동 선택은 GC573를 우선합니다. 다른 DirectShow 장치는 (실험적)으로 표시됩니다.
- 캡처 오디오 장치: 설정창에서 영상 장치 내부 Audio 핀을 먼저 확인해 감지되면 자동 사용으로 표시합니다. USB 캡처보드처럼 오디오가 별도 장치로 나타나면 이름이 일치하는 DirectShow 오디오 입력을 찾습니다. 자동으로 잡히지 않으면 목록에서 해당 USB 오디오 입력을 직접 선택하세요.
- 첫 실행의 기본 캡처 해상도는 1920x1080(FHD)입니다. 설정에서 고른 해상도는 다음 실행에도 유지되며, 설정 창이나 뷰어 창을 다른 모니터로 옮겨도 자동으로 바뀌지 않습니다.
- 장치나 해상도를 직접 바꿀 때만 지원 포맷/프레임 목록을 다시 읽습니다.
- 픽셀 포맷: 장치나 해상도를 바꾸면 지원 포맷을 자동으로 다시 읽습니다. 자동/NV12/YUY2 중 실제 제공하는 포맷만 표시합니다. NV12/YUY2가 모두 30fps 미만이거나 없으면 MJPEG도 표시됩니다. MJPEG는 Windows Media Foundation 디코더를 쓰는 베타 기능으로, 자동 선택에는 포함되지 않으며 직접 선택해야 합니다.
- 프레임: 선택 포맷에서 제공되는 프레임만 자동으로 다시 읽어 120/60/30fps 등을 별도로 선택합니다. 드라이버가 30fps를 범위 정보로만 알려도 지원 목록에 표시하고 캡처 핀 자체를 30fps로 설정합니다.
- 프레임 아래 '자동 인식' 줄은 현재 장치·해상도에서 감지한 전체 포맷/프레임 조합입니다. 지원 모드가 없으면 시작 버튼은 비활성화됩니다.
- 예: NV12/120fps 성능이 부족하면 NV12/60fps를 고릅니다. 캡처 핀부터 60fps로 작동하므로 120fps를 받은 뒤 버리는 방식보다 부하가 낮습니다.
- 자동 선택은 NV12를 우선합니다. YUY2는 8-bit 4:2:2 입력이 필요한 경우 직접 고를 수 있습니다.
- 진단 로그 파일 저장: 켜면 `%LOCALAPPDATA%\LowLatencyCaptureViewer\logs`에 실행 시각별 UTF-8 로그를 만듭니다.
- 언어 / Language: 자동(Windows 언어), 한국어, English 중 하나를 고릅니다. 언어는 하나의 실행 파일에서 전환되며 별도 영어판을 설치하지 않습니다.
- 장치 재연결 기능은 없습니다. 장치를 뺐다가 다시 연결한 경우 프로그램을 다시 실행합니다.
- 다른 캡처보드는 progressive NV12/YUY2 영상과 48kHz stereo PCM 오디오가 권장됩니다. 오디오는 같은 필터 또는 별도 DirectShow 오디오 입력 필터에 있어도 됩니다. MJPEG는 베타 호환 모드이며 장치별 동작을 보장하지 않습니다. H.264/AVC, MPEG-4와 P010은 지원하지 않습니다.
- 비디오와 오디오가 별도 필터일 때는 장시간 사용 중 Tab 정보창에서 불균형이 반복되면 클록 드리프트 보정을 켜세요.
- 시작 전 OBS, 제조사 캡처 유틸리티(예: Elgato 4K Capture Utility)처럼 같은 캡처보드를 사용하는 프로그램을 종료하세요. 장치가 점유 중이면 지원 모드여도 초기화에 실패할 수 있습니다.

오디오 설정
- GC573 입력 버퍼 선택은 제거됐습니다. 실제 packet/주기는 Tab OSD에서 확인합니다.
- 클록 드리프트 보정 끔: 리샘플링 없이 원본 PCM을 사용하며 지연이 가장 낮습니다. 기본값입니다.
- 자동 리샘플링: 장시간 안정성을 위해 PCM 버퍼와 최대 ±1000ppm 보정을 사용합니다.
- PCM 버퍼 목표는 리샘플링과 독립적으로 10/15/20/30ms 중 선택합니다.
- 10ms는 최저 지연, 15ms는 저지연 목표, 20ms는 안정 권장, 30ms는 안정성 우선입니다.
- PCM 버퍼 목표 옆 ? 아이콘에서 각 값의 지연·안정성 trade-off를 확인할 수 있습니다.
- 클록 드리프트 보정 옆 ? 아이콘: 마우스를 올리면 보정 필요 여부와 OSD 판독법이 표시되며, 누르면 전체 설명을 볼 수 있습니다.
- 영상 창 위에서 마우스 휠: 앱 음량을 5%씩 조절합니다.
- 음량 100%에서는 PCM 볼륨 연산을 완전히 건너뜁니다.
- `100% 이상 볼륨 증폭 허용 (최대 200%)`을 켜면 앱 음량을 200%까지 올릴 수 있습니다. 추가 버퍼나 프레임 큐는 만들지 않지만, 큰 원본 음량은 왜곡될 수 있으므로 실제로 작을 때만 사용하세요.
- 볼륨 HUD 위치는 설정에서 네 모서리 중 선택할 수 있으며 좌측 상단이 기본입니다.
- 백그라운드에서 자동 음소거: 다른 프로그램으로 전환하면 출력 게인만 0으로 낮추고, 다시 돌아오면 기존 음량을 복원합니다.
- 자동 음소거 중에도 캡처와 WASAPI 출력 소비는 계속되므로 PCM이 쌓이거나 복귀 지연이 추가되지 않습니다. 기본값은 꺼짐입니다.
- 다른 창에서 돌아올 때 일시적인 D3D11/Present 오류가 발생하면 영상 렌더러만 자동 재생성합니다. 캡처 그래프와 WASAPI는 유지됩니다.
- 창이 완전히 가려진 상태는 오류로 종료하지 않고 50ms 간격으로 표시 가능 여부만 확인한 뒤 자동 복귀합니다.
- 이 복구 검사는 실제 오류나 가림 상태에서만 실행되며 정상 재생 중의 지연과 프레임 경로는 바뀌지 않습니다.

화면 표시 방식
- 저지연: VSync 대기 없이 최신 프레임을 즉시 표시합니다.
- VSync: 모니터 주기에 맞춰 표시합니다.
- 화면 표시 방식 옆 ? 아이콘에서 두 방식의 지연·프레임 페이싱 차이를 확인할 수 있습니다.

화면 확대 방식
- 부드럽게: 기본 보간 방식입니다.
- 선명하게: GPU Video Processor의 가장자리 보강을 사용해 확대 화면의 UI·글자를 더 또렷하게 표시합니다. 프레임 큐를 추가하지 않아 표시 지연은 늘리지 않습니다. GPU 드라이버가 지원하지 않으면 부드럽게로 자동 대체됩니다.

오디오 출력 모드
- WASAPI Shared (호환성 우선 · 권장): Windows 오디오 시스템과 장치를 공유합니다. 다른 앱과 함께 사용하기 쉽고 장치 호환성이 높습니다.
- WASAPI Exclusive (지연 최소화 · 장치 독점): 선택한 출력 장치를 앱이 단독으로 사용합니다. 믹서 경로를 줄일 수 있지만 다른 앱과 동시에 사용하지 못하거나 장치가 지원하는 형식·주기에 제한될 수 있습니다.

구조
- 선택한 DirectShow 캡처 그래프와 캡처 필터는 각각 하나만 생성됩니다.
- 같은 그래프에서 영상 NV12/YUY2와 오디오 PCM을 함께 받습니다.
- 영상은 최신 프레임 하나만 유지하고 D3D11으로 직접 표시합니다.
- DXGI MaximumFrameLatency는 1입니다.

조작
- F5: 현재 모니터에서 정확한 1:1 크기로 복원합니다. 캡처 해상도와 모니터 해상도가 같으면 borderless 전체화면을 사용하고, 1:1이 모니터보다 크면 안내 HUD를 표시합니다.
- F11: 전체화면 전환
- F2: 캡처를 안전하게 종료하고 설정 창 다시 열기
- Tab: 실시간 정보 OSD 표시/숨기기
- 마우스 휠: 영상 창 위에서 볼륨 올리기/내리기
- 창 이동: 모니터 작업 영역의 네 변과 모서리에 가까워지면 창 크기 변경 없이 붙습니다.
- 스냅 해제: 붙은 뒤 화면 안쪽으로 조금만 움직이면 Shift 없이 즉시 떨어집니다.
- 모니터가 맞닿은 경계: 어느 방향으로든 20 DIP 계속 끌면 풀리므로 옆 모니터로 넘어갈 수 있습니다.
- 바깥쪽 모니터 경계: 어느 방향으로든 20 DIP 계속 끌면 풀리므로 Shift 없이 화면 밖으로도 옮길 수 있습니다.
- Shift를 누른 채 창 이동: 프로그램의 가장자리 스냅을 일시 해제합니다.
- Esc: 캡처 해상도와 모니터가 같아 자동으로 시작된 전체화면에서는 바로 종료합니다. F11로 직접 켠 전체화면은 먼저 해제하고, 창 모드에서 다시 누르면 종료합니다. 상대적 창 크기 유지가 켜져 있고 저장된 창이 모니터보다 작으면 그 비율을 우선합니다.

참고
- PC/드라이버가 요청 FPS를 지원하지 않으면 같은 해상도와 선택 포맷에서 적합한 지원 FPS를 자동 선택합니다.
- 실제 선택된 FPS는 창 제목, Tab OSD와 진단 로그에 표시됩니다.
- 초기화 실패 시 프로그램이 조용히 닫히지 않고 오류 코드 안내창을 표시합니다.
- Tab OSD와 볼륨 HUD는 별도 창이 아니라 같은 D3D11 프레임에 합성됩니다.
- 마지막 창 모드 위치와 모니터는 정상 종료 시 저장되고 다음 실행에 복원됩니다.
- 창 스냅은 설정에서 끌 수 있으며 기본값은 켜짐(권장)입니다.
- 스냅 진입·해제 거리는 각각 20 DIP이며 DPI에 맞춰 조정됩니다.
- 한번 해제되면 진입 구역 밖으로 나갈 때까지 같은 축에 다시 붙지 않습니다.
- 배율이 다른 모니터를 왕복해도 선택한 픽셀 퍼펙트 클라이언트 크기를 다시 정확히 맞춥니다.
- '모니터 이동 시 상대적 창 크기 유지'는 다른 해상도 모니터로 옮길 때 화면을 차지하는 비율을 유지합니다.
- 예: 4K 모니터의 QHD 창(66.67%)은 FHD 모니터에서 1280x720이 되고, 4K로 돌아오면 다시 2560x1440이 됩니다.
- Pixel-perfect를 켜면 선택 해상도와 1:1이 되며 마우스 창 크기 조절은 비활성화됩니다.
- Pixel-perfect 전체화면에서는 가능한 가장 큰 정수 배율로 표시하고 남는 영역은 검게 처리합니다. 캡처 해상도가 모니터보다 크면 화면 전체가 보이도록 비율을 유지해 축소합니다.
- Pixel-perfect를 끄면 마우스로 창 크기를 조절할 수 있고 영상 비율은 자동 유지됩니다.
- 상대적 창 크기는 Pixel-perfect와 독립적으로 켜고 끌 수 있습니다. 둘 다 켜면 다른 모니터로 이동할 때 화면 점유율을 맞추므로 1:1이 깨질 수 있습니다.
- 둘 다 켠 경우 상대 비율은 선택 해상도와 시작 모니터를 기준으로 매번 다시 계산됩니다. 이전 실행에서 저장된 작은 창 비율은 재사용하지 않습니다.
- Borderless 창도 Pixel-perfect가 꺼져 있으면 가장자리와 모서리에서 크기를 조절할 수 있으며, 제목 표시줄이나 밝은 상단 프레임은 추가되지 않습니다.
- 초기 설정창은 480 x 600 DIP이며 모니터 배율에 맞춰 전체 레이아웃이 조정됩니다.
- 이 PC의 GC573는 5ms와 20ms 요청 모두 실제 10ms PCM 패킷을 전달했습니다.
- OSD의 앱 처리 지연은 콜백부터 Present까지이며 총 HDMI/모니터 지연은 아닙니다.
- OSD의 오디오 오류는 underrun/overrun 횟수와 실제 부족/폐기된 PCM 시간을 함께 표시합니다.
- OSD의 클록 보정 줄은 리샘플러 적용 ppm과 정상/한계/출력부족 상태를 표시합니다.
- PCM 버퍼 줄은 현재값, 렌더 직전 목표, 관측된 최저값을 따로 표시합니다.
- 오류 원인은 입력 패킷 지연, PCM 버퍼 소진, 리샘플러 출력 부족으로 분리되며 합계가 underrun 횟수와 일치합니다.
- v0.14.1은 OSD 높이를 420픽셀로 확장해 아래쪽 진단 줄까지 모두 표시합니다.
- 용어: 출력 버퍼=WASAPI 장치 버퍼, 출력 점유=그 버퍼에 현재 들어간 양, PCM 버퍼=프로그램 내부 오디오 버퍼, PCM 버퍼 목표=재생 전 확보할 기준량입니다.
- '불균형 ppm(추정)'은 누적 PCM 차이와 실행 시간으로 계산한 참고값이며 하드웨어 클록을 직접 측정한 값이 아닙니다.
- 시작 직후 숫자만으로 판단하지 말고 10~30분 관찰합니다. '안정 · 보정 불필요'는 끔 유지, '드문 오류'는 체감 문제가 없으면 끔 유지, '반복 불균형 · 보정 권장'이 계속되면 자동 리샘플링을 권장합니다.
- 실행 직후 2초는 OSD 워밍업으로 제외됩니다. 영상과 소리는 즉시 실행되지만 FPS, 프레임, 오디오 오류와 최저 PCM 버퍼 통계는 2초 뒤부터 누적됩니다.
- 최신 NV12 샘플의 별도 CPU 프레임 복사는 제거됐습니다.
- GC573 시스템 메모리에서 D3D11 텍스처로 올리는 업로드 한 번은 남아 있습니다.
