LLCV v2.1.6 실행 안내
====================

영상 > 표시 모니터에서 시작할 모니터를 선택할 수 있습니다.
선택한 모니터가 없으면 주 모니터에서 시작하며, 실행 후에는 자유롭게 이동할 수 있습니다.
저지연과 VSync 모두에서 표시 문제가 있으면 호환성 출력 (Blt · VSync)을 비교해 보세요.
호환성 출력은 지연·GPU 부하가 늘 수 있고 HDR10 출력은 지원하지 않습니다.
화면 표시 방식과 호환성 출력 설명은 docs/VIDEO.ko.md를 보세요.

처음 실행
1. 캡처 장치와 사용할 헤드폰/스피커를 연결합니다.
2. OBS나 제조사 캡처 유틸리티 등 같은 캡처 장치를 사용하는 앱을 종료합니다.
3. LowLatencyCaptureViewer.exe를 실행하고 캡처 장치를 확인한 뒤 시작을 누릅니다.
4. 영상은 나오는데 소리가 없으면 설정의 캡처 오디오 장치를 확인합니다.
   영상·오디오가 별도 장치로 표시되는 USB 캡처보드는 맞는 오디오 장치를
   직접 선택해야 할 수 있습니다.

처음에는 WASAPI Shared, PCM 버퍼 목표 25ms, 자동 클록 보정을 권장합니다.
PCM 버퍼 목표는 10/15/20/25/30ms 중 선택할 수 있습니다.
이전 버전에 저장된 20ms 값은 첫 실행 때 한 번만 25ms로 바뀝니다.
다른 저장값은 유지되며, 변경 후 직접 다시 선택한 20ms도 유지됩니다.
25ms는 장치·드라이버별 무오류 재생을 보장하는 값은 아닙니다.

2.1.6에서 달라진 점
- 영상 → 업스케일링에서 끄기 / CMAA2 → NIS / NVIDIA VSR을 선택합니다.
  CMAA2 → NIS는 SDR 영상의 계단현상을 보정한 뒤 확대하며 기본 선명도는 0.15, 새 필터 기본값은 꺼짐입니다.
  표시 해상도가 캡처와 같으면 확대되지 않으므로 더 큰 표시 해상도를 선택하세요.
- 가로·세로 최대 2배 확대에 적용하며 HDR·원본 크기·축소·2배 초과는 기존 출력으로 처리합니다.
  화면 표시에만 적용하는 필터입니다.
- 설정 탭 전체의 간격·정렬·하단 여백을 맞췄습니다.
- 설정 화면의 불필요한 처리를 줄이고 수동 미리보기·측정 도구를 기본 빌드에서 제외했습니다.
- 테스트·비공개 미리보기의 설정 경로를 별도 임시 프로필로 분리했습니다.
  변경 내역: docs/release-notes-v2.1.6.md

재생 음소거 (2.1.3부터)
- F3 오디오 OSD·오디오 전용 화면의 스피커 버튼이나 M 키로 재생만 음소거합니다.
  기존 음량·녹화 소리는 유지하며, 단축키는 도움말·진단에서 변경할 수 있습니다.
- 영상의 음소거 아이콘은 녹화에 포함되지 않습니다. 휠 조절·음량 초기화로도 해제되며,
  앱 종료 시 음소거 상태는 초기화됩니다. 백그라운드 자동 음소거와는 별도로 동작합니다.

녹화·캡처 옵션 (2.1.1부터)
- MJPEG SDR 입력도 지원되는 H.264/HEVC/AV1 코덱으로 녹화합니다.
  추가 디코딩으로 CPU 사용량이 늘 수 있습니다. HDR·5.1 녹화는 지원하지 않습니다.
- 녹화 탭의 오디오(AAC) 옆에서 녹화 음량을 0~100%로 조절합니다.
  기본 100%, 0%는 무음입니다. 녹화 시작 전에 설정하며 재생 음량과 별개입니다.
- 영상 → 프레임 옆 추가 설정에서 목록에 없는 FPS 요청을 켜고 프레임을 30fps로 선택한 뒤 시작하세요.
  색상으로 구분된 직접 요청 표시는 지원 확인이 아닙니다. 드라이버가 거부하거나
  다른 FPS로 적용하면 안내하며 시작하지 않습니다. 시작 후 Tab의 실제 입력 FPS도 확인하세요.
- 녹화 설정 배치, 시작·종료 안정성과 저장 영상의 색 정보 처리를 보완했습니다.
- 기본 녹화 상한은 1080p·60fps이며 기존 설정·설치 경로는 유지합니다.
  사용법: docs/RECORDING.ko.md / 변경 내역: docs/release-notes-v2.1.1.md

단축키 설정
- 설정의 도움말·진단에서 키 버튼을 누르고 원하는 키를 입력하면 단축키를 바꿀 수 있습니다.
  Ctrl·Alt·Shift 조합도 지원합니다. 입력을 취소하려면 같은 버튼을 다시 누르세요.
- 녹화·음소거·Esc를 포함한 11개 모두 변경할 수 있습니다. 빈 칸·중복 키·일부 Windows 예약 조합은
  지정할 수 없습니다. 기본값 복원 버튼으로 단축키 전체를 되돌릴 수 있습니다.
- 시작을 누르면 변경·복원을 적용하며, 취소하면 적용 전 변경은 버립니다.
  안내창·설정·OSD에도 지정한 키를 표시합니다.
- 설정 창 안에서는 F4를 제외한 F1~F24 기능키 또는 해당 조합키로만 녹화를 조작합니다.
  Space·Enter·방향키 등은 설정 조작에 사용합니다. 재생 창에서는 지정한 조합을 그대로 사용합니다.
- 기존 단축키 기본값·설정·설치 경로는 유지합니다. 자세한 변경 내용: docs/release-notes-v2.0.5.md

40fps 캡처 (2.0.4부터)
- 영상 → 프레임 옆 추가 설정의 40fps 캡처는 기본 꺼짐입니다. 체크하면 드라이버에 40fps를 요청하며
  해제하면 기존 프레임 선택으로 돌아갑니다. 지원 여부는 시작할 때 확인합니다.
- 미지원 시 다른 FPS로 대체하지 않고 안내합니다. 끄고 기존 설정으로 재시도하세요.
  시작 후 Tab의 실제 입력 FPS도 확인하세요.
- 도움말·진단의 40fps 캡처 안내에서 동작과 주의사항을 확인하세요. 일반적인
  시청에는 기존 프레임 설정을 유지하면 됩니다. 게임 FPS 고정·VRR 대체 기능은 아닙니다.
- 기존 설정·설치 경로는 유지합니다. 자세한 변경 내용: docs/release-notes-v2.0.4.md
  사용 조건과 활용 예시: docs/VIDEO.ko.md

기존 설정 화면·절전 방지 기능
- 설정 정보를 백그라운드에서 조회하고 재사용합니다. 연결한 장치가 바뀌면
  설정의 새로고침을 누르세요. WASAPI/ASIO 전환 시 각 모드의 장치 선택을 유지합니다.
- 작은 화면에서는 상단의 설정 항목 목록으로 페이지를 이동합니다. 스크롤은 없습니다.
- 앱 설정의 재생 중 자동 절전 방지는 기본 켜짐입니다. 영상 재생 중에는 화면과
  시스템을 유지하고, 오디오 전용 모드에서는 화면 꺼짐을 허용합니다.
  재생이 끝나면 해제하며, 수동 절전과 Windows 전원 정책을 바꾸지 않습니다.
- 이전 변경 내용: docs/release-notes-v2.0.3.md

자주 쓰는 조작 (기본 키 기준 — 변경했다면 지정한 키 사용)
- F1: 앱 버전·단축키·마우스 조작 안내 (F1/Esc로 안내창만 닫기)
- F12: 입력 해상도 PNG 저장 (영상 모드)
- F2: 기본 설정 화면 열기 (녹화 중에는 녹화 마무리 여부 확인)
- Tab: 실시간 진단 정보 표시/숨기기
- F3: 오디오 미터 표시/숨기기
- M: 재생 음소거 전환 (녹화 소리는 유지)
- F5: 현재 모니터에서 가능한 경우 정확한 1:1 크기로 복원
- F6: NVIDIA VSR 요청 켜기/끄기 (영상 모드)
- F9: 녹화 시작/종료 (기본값, 기존 F9 사용자는 도움말에서 배정 키 확인)
- F11: 선택한 표시 방식의 전체화면 전환
- Esc: F11로 켠 전체화면은 해제, 창 모드 또는 자동 전체화면에서는 종료
- 뷰어 위 마우스 휠: 앱 음량을 5% 단위로 조절
- Shift를 누른 채 실행: 저장된 바로 시작 설정과 관계없이 설정창 열기

스크린샷
- 저장 위치: 사진 폴더의 LowLatencyCaptureViewer
- 영상 설정 최하단에서 저장 폴더 열기와 클립보드 복사를 설정합니다.
- P010 HDR10 입력은 파일·클립보드 모두 SDR로 변환합니다. HDR 원본 저장은 아닙니다.
- OSD·VSR·화면 필터는 제외하며, 한 번에 한 장씩 백그라운드에서 처리합니다.
- 저장 완료 안내를 확인한 뒤 종료하세요. 미완료 작업은 종료 시 취소됩니다.

문제가 있을 때
- 장치 분리나 입력 경로 오류로 멈추면 장치 상태를 확인한 뒤 설정에서 다시 시작합니다.
  자동으로 반복 검색하지 않습니다. 소스가 모든 스트림의 종료를 알리면 설정으로
  돌아가며, 일시적인 무신호만으로 이를 정상 종료로 처리하지 않습니다.
- 저장 실패 안내가 나오면 설정 파일의 쓰기 권한·디스크 공간·파일 잠금을 확인합니다.
  기존 파일은 보존되며, 저장하지 못한 변경은 다음 실행에 반영되지 않을 수 있습니다.
- 소리가 끊기면 Tab 진단 정보를 확인합니다. PCM 부족과 출력 지연 의심은
  서로 다른 진단이며, 출력 지연 의심 수치가 실제 음성 손실량은 아닙니다.
- 진단 로그 저장을 켜고 문제를 재현한 뒤 F2 설정의 도움말·진단 페이지에서
  로그 폴더를 엽니다. 로그는 다음 사용자 폴더에 저장됩니다.
  %LOCALAPPDATA%\LowLatencyCaptureViewer\logs
- 문의할 때 앱 버전, 캡처·출력 장치, 선택한 모드와 진단 로그를 함께 전달합니다.
- ASIO는 사용자 PC에 호환 드라이버가 설치된 경우에만 사용할 수 있습니다.
  ASIO 드라이버는 이 패키지에 포함되지 않습니다.
